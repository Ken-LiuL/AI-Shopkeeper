# AI店长 Chrome 扩展

本扩展专用于 **美团买药商家后台（yiyao.meituan.com）**，用于自动采集业务数据并同步到 AI 店长后端。

## 功能

- 自动拦截业务接口（订单、商品、评价、指标、库存、退款）
- 将数据推送到后端 `POST /api/sync/ingest`
- 支持在弹窗中配置后端 API 地址（默认生产地址）

## 安装

1. 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `chrome-extension/` 目录

## 配置

1. 点击扩展图标打开弹窗
2. 在「数据同步」中设置：
   - `后端服务器地址`（默认 `https://ai-shopkeeper-kk.fly.dev`）
   - `商户 ID`（可选）
3. 在「客服设置」中可选设置：
   - `客服 API 地址`（完整地址）
   - `客服 API 基础地址`（默认 `https://ai-shopkeeper-kk.fly.dev`）
4. 点击保存后可用「测试后端连接」验证可用性

## 使用

1. 打开并登录 `https://yiyao.meituan.com`
2. 浏览订单/商品/评价等页面
3. 扩展会自动采集并同步数据
4. 在弹窗查看同步统计和日志

## 说明

- 当前版本不再包含 QNH（牵牛花）页面适配逻辑
- 数据同步采用节流策略，避免短时间重复上报
