# AI店长 Chrome 扩展安装使用指南

这份文档是给第一次接触 Chrome 扩展的同事准备的。你不需要懂代码，只要照着下面的步骤操作，就可以把我们的 `AI店长 - 客服助手` 安装好并用起来。

## 这个扩展是做什么的

这个扩展主要用于 **美团买药商家后台** 的客服场景。

它能帮你做这些事：

- 自动识别顾客发来的新消息
- 调用 AI 生成回复建议
- 把建议显示在页面右侧悬浮面板里
- 按你的设置，支持三种工作方式：
  - `建议模式`：只给建议，你自己决定发不发
  - `半自动模式`：自动把建议填到输入框里，你检查后手动发送
  - `全自动模式`：自动填充并自动发送

注意：

- 这个扩展 **不是通用插件**，主要用于 `https://yiyao.meituan.com`
- 现在它主要负责 **AI 客服回复**
- 商品、订单、评价等数据采集，不再由这个扩展负责

## 安装前先准备好

开始前，请先确认你已经准备好下面几样东西：

- 一台安装了 Chrome 浏览器的电脑
- 扩展文件
  - 如果你拿到的是文件夹，通常名字叫 `chrome-extension`
  - 如果你拿到的是压缩包，通常名字叫 `chrome-extension.zip`
- 后端服务地址
  - 默认地址是 `http://192.144.227.205:8000`
  - 如果公司给了你别的地址，以公司提供的为准
- 你的美团买药商家后台账号

## 第一步：把扩展安装到 Chrome

### 方式一：你拿到的是文件夹

1. 打开 Chrome 浏览器
2. 在地址栏输入 `chrome://extensions`，然后回车
3. 打开右上角的 `开发者模式`
4. 点击左上角或页面上的 `加载已解压的扩展程序`
5. 选择你拿到的 `chrome-extension` 文件夹
6. 点击 `选择文件夹`

安装成功后，你会在扩展列表里看到：

- `AI店长 - 客服助手`

### 方式二：你拿到的是压缩包

如果你拿到的是 `chrome-extension.zip`，请先解压，再安装。

1. 找到 `chrome-extension.zip`
2. 右键点击它，选择 `解压` 或 `解压到当前文件夹`
3. 解压完成后，确认你看到了一个 `chrome-extension` 文件夹
4. 打开 Chrome 浏览器，进入 `chrome://extensions`
5. 打开右上角的 `开发者模式`
6. 点击 `加载已解压的扩展程序`
7. 选择刚刚解压出来的 `chrome-extension` 文件夹

注意：

- Chrome **不能直接安装 zip 压缩包**
- 一定要先解压，再选择解压后的文件夹

## 第二步：把扩展固定到浏览器顶部

为了方便以后使用，建议你把扩展固定到浏览器工具栏。

1. 点击 Chrome 右上角的扩展图标
2. 找到 `AI店长 - 客服助手`
3. 点击右侧的图钉
4. 固定后，浏览器右上角会一直显示这个扩展图标

## 第三步：第一次打开并配置

1. 点击浏览器右上角的 `AI店长 - 客服助手` 图标
2. 你会看到一个弹窗，里面有 `客服设置`、`反馈统计`、`调试日志` 三个标签页
3. 先在 `客服设置` 里完成下面几项

### 1）启用 AI 客服助手

- 确认 `启用 AI 客服助手` 这个开关是打开状态

### 2）选择回复模式

你可以根据自己的使用习惯选一个模式：

- `建议模式`
  - 最稳妥，推荐新手先用这个
  - AI 只出建议，不会自动往输入框里写
- `半自动模式`
  - AI 会自动把建议填入回复框
  - 你检查一下，确认没问题后再点发送
- `全自动模式`
  - AI 会自动填入并自动发送
  - 适合熟悉流程后再使用
  - 如果你是第一次用，不建议一上来就开这个模式

### 3）填写 API 地址

弹窗里有两个地址字段：

- `客服 API 基础地址`
- `客服 API 地址（留空用默认）`

推荐新手这样填：

1. 先只填写 `客服 API 基础地址`
2. 如果你们没有特殊说明，就填默认值：`http://192.144.227.205:8000`
3. `客服 API 地址（留空用默认）` 可以先留空

为什么可以留空：

- 扩展会自动使用默认接口地址
- 默认完整地址是：`http://192.144.227.205:8000/api/customer-service/chat`

### 4）填写店铺 ID（可选）

- `店铺 ID` 不是必填
- 如果公司明确给了你店铺 ID，就填上
- 如果没人要求你填，可以先留空

### 5）保存设置

1. 点击 `保存客服设置`
2. 看到 `已保存` 提示后，说明配置已经写入浏览器

### 6）测试连接

1. 点击 `测试连接`
2. 如果连接正常，你会看到：
   - 状态变成 `已连接`
   - 通常会显示绿色连接状态
3. 如果连接失败，请先不要继续使用，先检查：
   - 地址有没有写错
   - 后端服务是否已启动
   - 当前网络是否能访问该服务地址

## 第四步：进入美团后台开始使用

1. 打开 `https://yiyao.meituan.com`
2. 登录你的商家后台账号
3. 进入客服聊天页面
4. 正常接待顾客消息

只要扩展已启用，页面里通常会出现一个右侧悬浮面板，名字类似：

- `🤖 AI客服助手`

如果顾客发来新消息，扩展会自动识别，并根据当前模式执行对应动作。

## 第五步：看懂悬浮面板怎么用

悬浮面板是你日常最常用的地方。

它会显示：

- 当前工作模式：建议 / 半自动 / 全自动
- 当前有哪些会话
- 每个会话里有哪些 AI 回复建议
- 每条建议的处理状态

你可以在面板里看到这些按钮：

- `采纳`
  - 直接采用 AI 建议
  - 会把建议填入输入框
  - 如果你当前是全自动模式，还会自动发送
- `编辑`
  - 先修改 AI 建议，再使用修改后的版本
- `忽略`
  - 放弃这条建议，不使用
- `👍`
  - 给这条 AI 建议一个好评
- `👎`
  - 给这条 AI 建议一个差评

有些建议上可能还会看到这些提示：

- `建议转人工`
  - 说明 AI 判断这条对话更适合人工处理
- `已使用订单面板`
  - 说明 AI 回复时参考了页面上的订单信息

## 三种模式到底该怎么选

如果你不知道选哪种，直接看下面这张简单说明。

### 建议模式

适合：

- 第一次使用的人
- 想先观察 AI 回复质量的人
- 对自动发送比较谨慎的人

工作方式：

- 顾客来消息后，AI 给出建议
- 建议会显示在悬浮面板里
- 你自己决定采纳、编辑还是忽略

### 半自动模式

适合：

- 已经熟悉系统的人
- 希望提高回复速度，但仍想自己确认内容的人

工作方式：

- AI 自动把建议写进回复框
- 你检查一下内容
- 手动点击发送

### 全自动模式

适合：

- 非常熟悉业务规则的人
- 对自动化流程已经验证过的人

工作方式：

- AI 自动生成回复
- 自动填入输入框
- 自动点击发送

提醒：

- 这个模式风险最高
- 如果你面对的是投诉、退款、配送异常等复杂问题，建议谨慎使用

## 实际工作时建议这样操作

如果你是第一次上手，建议按下面的顺序来：

1. 先使用 `建议模式`
2. 连续观察一段时间，看看 AI 回复是否符合你们店铺要求
3. 如果质量稳定，再切换到 `半自动模式`
4. `全自动模式` 只建议在明确允许的业务场景下使用

这是最稳妥的使用顺序，能减少误发风险。

## 反馈统计怎么查看

点击扩展图标后，切到 `反馈统计` 标签页，你可以看到：

- 总建议数
- 已采纳数量
- 已编辑数量
- 已忽略数量
- 好评数量
- 差评数量

这些数据可以帮助你判断：

- AI 建议是否经常被采用
- 是否需要继续优化回复质量

如果你想重新开始统计，可以点击：

- `重置统计`

## 调试日志有什么用

如果你遇到“没有建议”“连不上服务”“消息没反应”等问题，可以打开：

- `调试日志`

这里会记录一些关键运行信息，比如：

- 连接测试是否成功
- 是否成功识别到消息
- 是否调用了后端接口
- 是否出现错误

当你需要找技术同事帮忙时，最好把这里的报错内容一起发过去。

## 常见问题

### 1. 扩展安装不上怎么办？

先检查这几件事：

- 你是不是打开了 `开发者模式`
- 你选择的是不是 `chrome-extension` 文件夹
- 如果你拿到的是 zip，是不是已经先解压

### 2. 我点了扩展图标，但不会用

先做这三步：

1. 打开 `客服设置`
2. 选择 `建议模式`
3. 填好 `客服 API 基础地址`，然后点击 `保存客服设置` 和 `测试连接`

只要测试连接成功，再去美团客服页面使用即可。

### 3. 进入美团后台后，没有看到悬浮面板

按顺序检查：

- 你打开的是不是 `https://yiyao.meituan.com`
- 你是否已经登录商家后台
- 当前页面是不是客服聊天页面
- 扩展是否处于启用状态
- 刷新一下页面再试一次

### 4. 点击测试连接失败怎么办？

最常见的原因有这些：

- `客服 API 基础地址` 填错了
- 后端服务没启动
- 网络不通
- 公司内网、代理或防火墙限制了访问

可以先问技术同事确认服务地址是否正确。

### 5. AI 没有自动回复，是不是坏了？

不一定，先看你当前选的模式：

- 如果是 `建议模式`
  - AI 只会在面板里给建议，不会自动发消息
- 如果是 `半自动模式`
  - AI 会自动填到输入框，但你要自己点发送
- 如果是 `全自动模式`
  - 才会自动发送

### 6. 什么时候应该转人工？

如果你看到 `建议转人工`，或者顾客问题比较复杂，建议不要强行用自动回复，比如：

- 投诉
- 退款纠纷
- 药品风险问题
- 配送异常升级
- 顾客情绪激动

这类情况更适合人工接手。

## 给新手的推荐设置

如果你希望最稳妥地开始，直接照这个配置：

- 启用 AI 客服助手：`打开`
- 回复模式：`建议模式`
- 客服 API 基础地址：`http://192.144.227.205:8000`
- 客服 API 地址：`留空`
- 店铺 ID：`留空（除非公司要求填写）`

然后：

1. 保存设置
2. 测试连接
3. 登录 `yiyao.meituan.com`
4. 进入客服页面开始使用

## 最后再提醒一次

第一次使用时，请优先选择 `建议模式`。

原因很简单：

- 更安全
- 更容易观察 AI 质量
- 不容易误发消息

等你确认回复效果稳定以后，再考虑切换到 `半自动模式` 或 `全自动模式`。
