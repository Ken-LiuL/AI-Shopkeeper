# Extension Icons

这个目录需要包含以下图标文件：

- `icon16.png` - 16x16 像素，用于扩展管理页面和浏览器工具栏
- `icon48.png` - 48x48 像素，用于扩展管理页面
- `icon128.png` - 128x128 像素，用于 Chrome Web Store

## 图标设计要求

- 图标应该简洁明了，体现 AI 店长的品牌形象
- 建议使用蓝色系配色，与 UI 主色调保持一致
- 图标需要在白色背景和深色背景上都有良好的可见性

## 临时解决方案

在开发阶段，可以使用在线工具生成简单的占位符图标，或者从 favicon 生成器创建基础图标。

制作完成后，请将图标文件放置在此目录下。
